# Wine Classification Using Gradient Descent and Backpropagation

This project applies machine learning techniques to classify wine types using the
scikit-learn Wine dataset.

## Methods Used
- Stochastic Gradient Descent (SGD)
- Batch Gradient Descent
- Backpropagation with early stopping
- ReLU and tanh activation functions
- Grid Search and Random Search for hyperparameter tuning
- K-Fold Cross-Validation

## Results
The final optimized model achieved approximately **96% test accuracy** with strong
precision, recall, and F1-scores across all three wine classes.

## How to Run
Open `Week2_wine.ipynb` and run all cells sequentially.
